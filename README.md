# Moog Light Synth V3

This synth has a pulse-width-modulated (PWM) oscillator and a light-controlled resonant low-pass filter. You play it with light, on two light-dependent resistors (LDRs), and with 13 keys.

- Video on YouTube: not available yet.

## Features

- PWM oscillator with a "growling" sound, through a high-resonance low-pass filter
- 2 LDRs control the oscillator
- 13 keys: play it as a 1-octave keyboard
- 2 drone oscillators (40106 hex inverter), which you can switch off. Thus there are 3 oscillators in total.
- Echo and reverb module, changed to add feedback
- Arpeggiator
- You can also play it with one potentiometer and the LDRs only

## What you need

- The Gerber files for the PCB are in `Moog Light Synth V3 - Gerber Files.zip`. You can send them to a PCB maker.
- The parts list is in the Instructables guide.

> **Note:** These design files are not in this repository yet:
> - Eagle files (schematic and board)
> - Front panel design

## Build it

The Instructables guide shows each step, with photos. In short:

1. Send the Gerber files to a PCB maker.
2. Get the parts in the parts list.
3. Solder the parts to the PCB.
4. Connect the power and test the circuit.
